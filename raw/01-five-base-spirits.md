# 01. 認識調酒世界的五大基酒 (Five Base Spirits)
- **來源類型**：基礎烈酒百科筆記
- **核心內容**：
  調酒中的「基酒」是指酒精度通常落在 40% ABV 左右的蒸餾烈酒，決定了一杯調酒的骨架與主體風味：
  1. **伏特加 (Vodka)**：以穀物或馬鈴薯多次蒸餾並經活性碳過濾，無色無味、口感純淨，能融入任何果汁或茶飲而不搶味，是最百搭的入門基酒。純酒精密度約 0.79 g/cm³，理論上純度高的烈酒比純水（1.00 g/cm³）輕。
  2. **琴酒 (Gin)**：在中性烈酒中加入杜松子（Juniper）與多種草本植物、柑橘皮重新蒸餾，帶有明顯的松針木質與森林草本清香。
  3. **白蘭姆酒 (White Rum)**：以甘蔗汁或糖蜜發酵蒸餾而成，未經橡木桶長期陳年，保留甘蔗的淡淡清甜與熱帶果香，適合搭配薄荷與檸檬。
  4. **龍舌蘭 (Tequila)**：以墨西哥藍色龍舌蘭草心蒸餾而成，帶有獨特的植物泥土氣息、微辛辣感與煙燻木質尾韻，常與檸檬、鹽巴或葡萄柚搭配。
  5. **威士忌 (Whiskey)**：以大麥、玉米等穀物發酵蒸餾並放入橡木桶陳年，呈琥珀色澤，具有香草、焦糖、煙燻與木質單寧的厚實風味，適合搭配氣泡水（Highball）或可樂。
